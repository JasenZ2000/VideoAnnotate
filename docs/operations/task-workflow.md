# 标注协作流程

1. 发布者登录后点击“发布”，从任务表复制任务行，设置产品标签；简单任务可按数量生成 Part，目录结构复杂时可双击 `PartDirectoryScannerTool.exe`，选择根目录、扫描并复制工作目录清单，再粘贴到发布窗口。
2. 标注者打开任务并领取下一个 Part。领取成功后，Part 卡片会显示并允许复制实际工作目录，同时立即开始计时；同一任务不能同时持有两个进行中或已暂停的 Part，发布者也可以领取自己发布的任务。标注者可以暂停后继续计时，也可以填写原因并中途退还；退还后 Part 重新进入待领取，下一位标注者从零计时，原计时段仍保留在历史和人员累计工时中。
3. 标注者完成后填写备注并提交。提交停止当前计时，之后可以继续领取待处理 Part。
4. 发布者或管理员在审核区检查待审核 Part：同意后完成；填写修改意见后退回原标注者。
5. 原标注者点击“开始修改并计时”，修改完再次提交备注提醒发布者或管理员复审。
6. 发布者可以随时编辑任务信息、追加 Part 或删除任意状态的 Part；删除进行中 Part 会立即将其从标注者界面移除。发布者还可以指定一名协同查看人、填写每 Part 预计耗时。协同查看人可以看到全部 Part 和人员统计，但不能编辑或审核。实际耗时偏差达到 50% 后，发布者可在 Part 卡片确认预估是否合理。修改后的前缀用于之后追加的 Part，已有 Part 不改名。
7. 管理员可在左侧任务列表填写排名并选择低、中、高、加急优先级。数字越大越靠前；每次排名或优先级变化都会记录操作人、旧值、新值和操作时间，并显示在任务详情的操作日志中。
8. 发布者可以删除自己发布的任意状态任务。删除后任务立即从所有人的任务列表中隐藏。

平台只记录协作状态和路径文本。视频、图片、标注文件和说明书仍位于任务表给出的共享文件系统中。
