# 任务标准作业流程

## 1. 发布任务

发布人创建任务时填写：

- 任务类型：通用标注或视频目标检测；
- 发布人、负责人和可领取任务的标注员名单；
- 完整任务说明；
- 初始 Part 数量；
- 视频检测任务需要的类别表和 LocateAnything 提示词。

发布人可以在“资料附件”中上传规范文档、示例、脚本、安装软件或其他辅助文件。平台只提供保存与下载，不会执行附件。

## 2. 负责人规划 Part

负责人根据任务规模批量创建 Part。Part 默认进入“待领取”池，不预先固定分配给某个标注员。执行中可以继续增加 Part。

每个 Part 都有独立状态、当前标注员、累计工时、提交备注、验收备注和问题数量。

## 3. 标注员动态领取

标注员完成手头工作后点击“领取下一个 Part”。平台通过 SQLite 事务原子领取编号最靠前的待处理 Part，避免多人同时拿到同一份工作。

领取成功后立即开始计时。标注员可以：

- 完成后提交，停止本次计时；
- 暂时无法处理时释放，停止计时并放回公共队列；
- 上传与该 Part 相关的资料；
- 报告任务级或 Part 级问题。

## 4. 问题排查

问题单记录严重程度、报告人、所属 Part、描述和解决结果。发布人或负责人负责处理和关闭问题。负责人可以结合未解决问题和 Part 耗时判断规范是否不清楚、数据是否异常或工具是否失效。

## 5. 提交、验收与返工

标注员提交后，Part 进入“待验收”。发布人或负责人可以：

- 验收通过，将 Part 标记为“已完成”；
- 填写返工要求并退回原标注员。

返工开始时创建新的计时会话，最终耗时为所有标注和返工会话之和。

## 6. 视频目标检测预处理

只有视频目标检测任务显示“视频预处理”工作区，并由发布人或负责人操作。

1. 上传完整视频。
2. 如果发布人已有 YOLO 预标注，则上传 ZIP；否则负责人运行 LocateAnything。
3. 长视频按目标密度和工作量拆分。
4. 负责人运行跟踪与轨迹融合。
5. 按设置帧数插值轨迹内部的短缺漏。
6. 得到初始轨迹后创建 Part，开放给标注员领取。

## 7. 本地视频审核与导出

当前整段视频支持生成标注包、员工本地 Annotator 清理、SAM3.1 辅助跟踪、审核结果上传和 YOLO 导出。

分段 LocateAnything 和分段跟踪已经可用，但分段标注包、审核回传和最终合并仍未形成完整闭环，正式任务需要负责人核对文件路径和结果。

## 当前身份边界

当前操作人由浏览器本地记录，后端根据任务人员名单校验业务操作权限。系统尚未接入登录、单点认证或不可伪造的用户身份，因此只适合可信部门内网。
