# 标注协作流程

1. 发布者登录后点击“发布”，从任务表复制一行或多行，设置产品标签、Part 数量和前缀。
2. 标注者打开任务并领取下一个 Part。领取成功立即开始计时，同一任务不能同时持有两个进行中的 Part。
3. 标注者完成后填写备注并提交。提交停止当前计时，之后可以继续领取待处理 Part。
4. 发布者在审核区检查待审核 Part：同意后完成；填写修改意见后退回原标注者。
5. 原标注者点击“开始修改并计时”，修改完再次提交备注提醒发布者复审。
6. 发布者可以随时追加 Part；新 Part 沿用任务创建时的前缀并继续编号。

平台只记录协作状态和路径文本。视频、图片、标注文件和说明书仍位于任务表给出的共享文件系统中。
